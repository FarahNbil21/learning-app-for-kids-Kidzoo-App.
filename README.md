# Kidzoo – Educational App for Kids

Kidzoo is a simple educational mobile application designed for kids to learn basic concepts through a colorful and child-friendly interface.

## Features

-  **Letters:** Displays the alphabet with images for each letter.
-  **Numbers:** Helps children recognize and learn numbers.
-  **Shapes:** Introduces basic shapes through visual content.
-  **Animals:** Displays different animals with corresponding images.
-  **Number Comparison Game:** A simple interactive game where the child chooses the larger of two numbers.
  - Shows a correct message when the answer is right.
  - Shows an incorrect message when the answer is wrong.

## Technologies

- Flutter
- Dart
- Cubit for state management
